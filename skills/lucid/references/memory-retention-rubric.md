# Memory Retention Rubric

Keep memory only when it is all of:

1. Durable: useful across future sessions.
2. Current: aligned with the active source of truth.
3. Actionable: changes what the agent should do.
4. Scoped: applies to a user, repo, project, team, skill, or agent.
5. Evidence-backed: traceable to a file, command, schema, decision, or repeated preference.
6. Safe: does not contain secrets, credentials, or unnecessary personal detail.

Remove or review memory when it is:

- one-off
- temporary
- obsolete
- too granular
- negative-only
- duplicative
- unverifiable
- sensitive
- copied from a single chat without durable relevance
